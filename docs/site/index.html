Add it to your pipeline

01 Build · Rust

set -eu
git clone https://github.com/megasoft1978/lcovmerge.git
cd lcovmerge && make

Stable Rust, Python 3.11+, Make. Build and download guide.

02 Merge, then report

# The shell expands this pattern; lcovmerge does not.
./bin/lcovmerge coverage/shard-*.info -o coverage/merged.info
genhtml coverage/merged.info --output-directory coverage/html

GitHub Actions

Merge downloaded LCOV shards in your final job.

- name: Merge LCOV shards

Limits

LCOV only. No .gcda or .profraw. Native policies differ from lcov -a; the experimental 2.6 profile remains under validation.

./bin/lcovmerge --lcov-compat=2.6 -a 'coverage/shard-*.info' -o coverage/merged.info

Merge only: no capture, reset, extract, genhtml, Perl callbacks, or automatic lcov replacement. Profile scope and status ↗
