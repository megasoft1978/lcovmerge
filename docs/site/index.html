Report format

LCOV output works with your existing genhtml or upload step.

Limits

Exported .info only; no .gcda, .profraw, capture, reset, or reports. Native differs from lcov -a; profile 2.6 is experimental.

./lcovmerge --lcov-compat=2.6 -a 'coverage/shard-*.info' -o coverage/merged.info
