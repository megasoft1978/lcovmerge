# Support

For usage questions, first check the [FAQ](docs/FAQ.md), [usage reference](docs/USAGE.md), and [integration
examples](docs/INTEGRATIONS.md).

For reproducible bugs or feature requests, open an issue in the [GitHub issue
tracker](https://github.com/megasoft1978/lcovmerge/issues). Include the lcovmerge version, operating system,
command line, exit code, and a small sanitized tracefile when possible. Avoid posting proprietary source paths
or coverage records.

For parser memory-safety vulnerabilities, use the private process in [SECURITY.md](SECURITY.md), not a public
issue.

Support is community-based. There is no paid support or response-time commitment.
